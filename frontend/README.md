# Frontend - TFG Kanban

Cliente web del proyecto Kanban, construido con React, Vite y TypeScript.

## Requisitos

- Node.js 20 o superior.
- Backend en ejecución y accesible desde el navegador.

## Instalación

```bash
npm install
```

## Ejecución

```bash
# Desarrollo (expuesto en red local)
npm run dev

# Build de producción
npm run build

# Vista previa de build
npm run preview
```

## Calidad

```bash
npm run lint
```
